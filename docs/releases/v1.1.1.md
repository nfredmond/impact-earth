# Impact Earth 1.1.1

This release adds ways to explore an event from a specific location, compare its dimensions, and keep an experiment.

- **Experience Tunguska:** five chapters with historical sources, an atmospheric cutaway, observer distances, material comparisons, and saved field notes.
- **Observer mode:** search 3,000 cities, enter coordinates, or select a point on Earth. See distance, bearing, modeled zones, and the route to ground zero. Include the observer in exported reports.
- **Scale studio:** compare asteroid or eruption dimensions on a shared linear scale, adjust size, and place a hypothetical crater or caldera outline at the observer location.
- **Globe controls:** focus view, catalog search and filters, animation playback, layer controls, mobile navigation, and reduced-motion support.
- **Desktop verification:** release builds run a native journey through the story, material experiment, population data, and saved notebook on Linux, Windows, and macOS. Publication waits for all three platforms. Linux uses the installed Debian package; Windows and macOS checks use their packaged executables.

The Linux CI runner uses software rendering for its virtual display. Normal desktop launches retain their default rendering settings. The 1.1.0 candidate was not published because the Linux virtual display blocked WebGL.

The build and lint checks pass without warnings. Shared code is split into smaller bundles; report generation loads on demand.

Download the `.deb` or `.AppImage` for Linux, `Setup.exe` for Windows, or the universal `.dmg` for macOS. Windows has no signing certificate, and macOS has no Apple notarization. Native CI checks do not verify every operating-system installation prompt or hardware configuration.

Saved notes stay on the device. Export them as HTML to keep a separate copy. Observer zones simplify the event and do not resolve arrival times, terrain shielding, sightlines, directional ashfall, or coastal tsunami exposure. The checks validate application behavior, not the scientific accuracy of the model.
