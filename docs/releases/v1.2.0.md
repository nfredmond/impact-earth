# Impact Earth 1.2.0

- **Local observer maps:** offline coastlines, rivers, city labels, distance rings, and effect boundaries. Center on the event, observer, or baseline and choose a map radius.
- **Graphics recovery:** the local map and controls stay available if 3D cannot start or loses its graphics connection. Retry in low detail without losing the scenario.
- **Scenario comparison:** pin a baseline, change the current inputs, compare numerical differences, and view both footprints.
- **General notebook:** save impacts and eruptions with their observer and baseline. Export editable JSON files, preview imports, and reopen experiments. Existing Tunguska field notes remain available.
- **Sensitivity experiments:** vary diameter, entry speed, entry angle, or erupted volume. Inspect lower/current/higher cases and compare a case with the original. The app identifies these as sensitivity cases, not confidence intervals.
- **Result updates:** hidden tabs update numerical results without waiting for animated frames.

The desktop release workflow checks the story and experiment journeys on Linux, Windows, and macOS. The 56-test suite covers application behavior; it does not validate the scientific model. Tests with new users remain pending, with a protocol in `docs/experiment-workbench.md`.

The regional map uses generalized present-day geography, not street detail or historical reconstruction. Windows builds are unsigned, and macOS builds are not notarized. Interactive installer prompts are outside the native journey checks.
