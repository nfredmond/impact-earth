# Impact Earth 1.2.1

Includes the offline regional map, graphics recovery, scenario comparison, notebook import/export, and sensitivity experiments from 1.2.0.

- Numerical results now update immediately with the scenario. Frame-based number animations could leave old totals visible when rendering slowed down on Linux.
- Short desktop windows scroll the local map at a readable height, with space between its heading, scale, and controls.
- The packaged desktop check now verifies the displayed population and exposure totals after reopening a saved experiment.

The 56-test suite covers application behavior, not scientific model validation. New-user testing remains pending. Windows builds are unsigned and macOS builds are not notarized.
